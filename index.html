progression strategy
Phase 1 — Months 1–2: Foundation
Learn movement patterns, build work capacity. Double progression — add weight only when top of rep range is hit for all sets 2 weeks running.
Phase 2 — Months 3–4: Accumulation
Add 1 set per compound. Introduce weekly top sets — heavy 3–5 rep set before back-off sets. Strength and size accelerate here.
Phase 3 — Months 5–6: Intensification
Deload week every 4th week (50% volume). Focus on rep PRs and full ROM. Physique consolidates. Reassess after month 6.

Daily supplement stack
Creatine monohydrate
Must-have #1
5g daily, any time, with water. No loading needed. More reps → more strength → more muscle. Fuller muscles within 2–3 weeks.
Brands: AS-IT-IS, MuscleBlaze · Cost: ~₹600–800/month
Whey protein
Already using ✓
2 scoops post-workout in milk. ~24–26g protein/scoop. Avoid mass gainers.
Recommended: MuscleBlaze Biozyme, ON Gold Standard
Vitamin D3 + K2
Strongly recommended
Most Bangalore desk workers are D3-deficient. Critical for testosterone, bone health, recovery.
Dose: 2,000–4,000 IU D3 + 100mcg K2 daily · ~₹300–400/month
Magnesium glycinate
Recommended
Improves sleep depth and recovery. 300–400mg before bed. Glycinate only (not oxide).
Cost: ~₹400–500/month
Omega-3 (fish oil)
Recommended
